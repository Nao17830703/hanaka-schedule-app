# Hana専用 スケジュール＆お出かけマネージャー

放課後等デイサービス（放デイ）と移動支援の毎月の利用希望スケジュールを、学校行事や祝日と照らし合わせて自動算出し、アナログな提出業務（FAX申込用紙）を自動化・効率化するWebアプリケーションです。

---

## 🌟 特徴と機能

1. **Mac / iPad 最適化 (Calm & Modern UI)**
   - Appleライクなシンプルで温かみのあるデザイン。
   - iPadでのタップ操作（指での直感的なタッチ）を重視した大きめのボタンとカード配置。
2. **放デイ カンニングペーパー機能 ＆ 利用日振替・帰宅時間手入力（NEW!）**
   - 「毎週木曜日」＋「隔週土曜日（第1・第3土曜）」を来月カレンダーに自動展開。祝日は自動除外。
   - **隔週土曜日の振替・利用日変更**: 月によって変動する土曜日利用を考慮し、放デイ編集画面から「今月の土曜日クイック振替チップ（第1土〜第5土）」をワンタップするだけで別週の土曜日に即座に移動可能！
   - カレンダー上の未登録土曜マスにも `[+ 土曜放デイ追加]` ボタンを設置し、直接追加もワンタッチ。
   - **送迎到着時間の手入力対応**: カレンダー上の放デイバッジをタップし、送迎車の運行ルートや同乗順に合わせて「17:15着」「17:45着」などを指先ワンタップ（または手入力）で簡単に調整可能！
   - バッジにも `🎈 放デイ 〜17:45着 [ON]` とわかりやすく表示。
3. **学校下校時間（スクールバスお迎え時間）の常時表示 ＆ 手動修正（NEW!）**
   - 曜日ヘッダーに基本下校時間「水 (14:00下校)」「平日 (15:00下校)」を固定表示。
   - 各日付マスに「当日の下校時間（🚌 15:00下校 等）」を明記。短縮授業・午前下校日（11:30など）は赤色バナー＋アニメーションで注意喚起し、バス逃しを徹底防止！
   - 学年別（高等部/中等部など）の微妙な時刻差も、カレンダーからワンタップで手動修正・編集可能。
4. **学校お便り解析モジュール (Gemini API連携)**
   - 『★こやの里お便り』の行事予定表（PDFまたは画像）をドラッグ＆ドロップ。
   - Gemini APIが「早帰り・短縮日課（給食なし等）」や「特別行事」を自動抽出し、カレンダー＆空き枠計算に即座に反映。
5. **移動支援 平日放課後（短時間枠）の自動割り出し ＆ 在庫管理（大幅強化!）**
   - 「放デイが入っていない平日（月・火・水・金）」を、**平日放課後の短時間枠（15:00〜17:30など約2.5時間）** として最優先で自動抽出！
   - 近所の公園や散歩、カフェなど短時間での平日利用をサクサク計画可能。
   - カレンダー画面からも、放デイのない平日に `[+ 平日移動支援]` ボタンでワンタップ登録。
   - 将来の遠出に向けた「日曜日・休日午後枠」もフィルターで切り替えて利用可能。
6. **移動支援の「確定 / 見送り」ステータス管理 ＆ 在庫復活ロジック**
   - 事業所からの回答に合わせて、ワンタップで `[✓ 確定]` または `[✕ 見送り]` に切り替え可能。
   - **在庫復活ロジック**: 事業所の枠が取れず「見送り」になった場合、割り当てられていた行き先スポットは自動的に「★ 未達・希望中（在庫）」リストに復帰！次月以降の候補として即座に再利用できます。
7. **Google / Appleカレンダー一括登録 (.ics エクスポート)（NEW!）**
   - 画面上部の **「カレンダー書出 (.ics)」** ボタンをワンタップするだけで、放デイ（利用日・時間帯）、移動支援（確定・希望日程）、学校行事（早帰り等）がすべて入った標準 `.ics` ファイルを出力。
   - iPadやMacのSafariで開いて標準カレンダーやGoogleカレンダーへ一括登録できます。
8. **かいと支援センター専用 FAX依頼表 完全再現 ＆ A4横PDF出力（大幅リニューアル!）**
   - 背景画像を敷くのではなく、原本のフォーマット（罫線・枠・フォント・配置）をコードで忠実に完全再現！
   - **用紙サイズ・向き**: A4横（Landscape: 1754×1240高精細）。
   - **完全再現項目**:
     - 左上「依　頼　表」二重枠タイトル ＆ 右上「次月依頼は２０日必着となります。ご注意ください。」注意文。
     - ヘッダー欄（ご依頼月・お名前・通し番号「全部で○枚中○枚目」）。
     - データ表（6行、7項目: 依頼日、曜日、開始時間、終了時間、待ち合わせ場所、行き先・伝達事項、ヘルパー名）。表外左側に行番号 1〜6。
     - フッター（左下太矢印「◀ ＦＡＸ送信方向」、中央「有限会社 かいと支援センター 行」、右下「（ＦＡＸ） ０６－６４３６－０９０９」）。
   - 画面プレビュー・PDF出力（pdf-lib）・ブラウザ直接印刷（AirPrint）のすべてで美しい原本クオリティを保証。
9. **iCloud連携 & GitHub Pagesホスティング**
   - サーバー不要の完全静的SPA（HTML/CSS/Vanilla JS）。
   - 「iCloud保存」「iCloud読込」ボタンから、iCloud Drive経由でMac/iPad間でのデータ同期が可能。

## 🚀 使い方

### 1. ローカルでの動作確認（Mac）
ブラウザで直接 `index.html` を開くか、ローカルサーバーを起動します：
```bash
cd /Users/nao/.gemini/antigravity/scratch/hanaka-schedule-app
# Pythonなどの簡易サーバーで開く場合
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` にアクセスします。

### 2. GitHub Pagesへのデプロイ
1. GitHubにリポジトリ（例: `hanaka-schedule-app`）を新規作成。
2. このフォルダのファイルをプッシュ：
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 華佳ちゃんスケジュール＆お出かけマネージャー"
   git branch -M main
   git remote add origin <あなたのリポジトリURL>
   git push -u origin main
   ```
3. GitHubリポジトリの **Settings > Pages** で「Deploy from a branch (main / root)」を選択。
4. 発行されたURL（`https://<ユーザー名>.github.io/hanaka-schedule-app/`）にiPadやMacのSafariからアクセスしてブックマークまたは「ホーム画面に追加」！
